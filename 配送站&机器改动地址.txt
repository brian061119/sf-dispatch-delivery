三、说明
------------------------------------------------------------
1. server/target/ 需重新构建生成，覆盖后执行：
       cd server
       mvn -q -DskipTests package
       java -jar target/sf-dispatch-delivery-server-1.0.0.jar

2. 测试代码共 8 个类 40 个用例，跑法：
       cd server && mvn -B test
   （本机 mvn 不在 PATH，可用 IntelliJ 自带的 Maven；
     注意 IntelliJ 自带的 JBR 是 JDK 25，编译 Java 11 目标需改用 PATH 上的 JDK 17）

3. 其中 3 个文件是跨模块改动，覆盖前请与对应模块的同学确认：
       service/OrderService.java      锁车时置 IN_DELIVERY 并同步载具实时信息
       service/TrackingService.java   追踪推进时回写载具坐标，返站归位转待命
       config/SecurityConfig.java     放行 /api/stations/**、/api/vehicles/**
   另外 resources/data.sql 修正了三个种子账号的 BCrypt 密码串，会影响认证模块。
